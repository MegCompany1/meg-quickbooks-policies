Connect or reconnect QuickBooks

MEG QuickBooks Integration · Meg Company Inc.

The MEG QuickBooks Integration is a private, internal tool used only with Meg Company Inc.'s own QuickBooks Online company. It is not available for other businesses to connect.

For authorized MEG staff

  1. Start the connection from the integration in Claude Code on an authorized MEG computer. It opens Intuit's sign-in page.
  2. Sign in to QuickBooks Online with an account that has access to MEG's company, and approve the requested read-only access.
  3. Return to Claude Code once Intuit confirms the connection.

If the connection has expired or was disconnected, repeat the same steps to reconnect.

Need access or help? Contact tech@megcompany.com.
